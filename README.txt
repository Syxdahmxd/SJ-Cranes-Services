SJ CRANES SERVICES - WEBSITE PACKAGE

FILES
- index.html: page content and structure
- style.css: responsive orange, black and white website design
- script.js: mobile navigation, current year and WhatsApp enquiry form
- sj-cranes-logo.jpg: supplied company logo (keep this beside index.html)

PREVIEW
1. Extract this ZIP file.
2. Open index.html in Chrome.
3. Internet access is required for Google Fonts and the remote illustrative photos.

PUBLISH ON GITHUB PAGES
1. Open your repository: https://github.com/Syxdahmxd/SJ-Cranes-Service
2. Upload/replace index.html, style.css and script.js in the repository root.
3. Keep sj-cranes-logo.jpg in the repository root.
4. Commit the changes. GitHub Pages should rebuild automatically.
